# Algorithm Efficiency Evaluation

## Core idea
Two ways to evaluate an algorithm: **actual testing** (run it, time it — unreliable
because results depend on hardware and input size) vs **theoretical estimation /
complexity analysis** (reason mathematically about how resource usage grows with
input size `n`, ignoring absolute values and hardware). Complexity analysis cares
about the **growth trend**, not the exact runtime.
